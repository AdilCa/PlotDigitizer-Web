## 0. 通用规则（三类手势共用）

| 规则 | 内容 | 依据 |

## 1. DrawAxis（DrawXAxis / DrawYAxis 步）

| 手势 | 行为 | 状态流转 |
|---|---|---|
| 空白处按下拖拽 | 画近似轴线（仅预览层，虚线） | idle → drawing |
| 松开 | 发 intent `fitAxis` → AxisFitter 拟合 → 成功：精拟合线（实线）+ 扫描带/质心/残差内联画出；失败：画候选线与内/外点标记，状态栏文字说明原因，**不写入 model** | drawing → fitted / failed |
| 已有轴时再次拖拽 | 预览线画在旧轴上方，旧轴高亮 + 状态栏"松开以替换现有 X 轴"；松开 = 替换（直接变更，替换前有视觉预告） | fitted → drawing → fitted |
| Delete / 右键点轴 | 删除该轴并级联删除其全部刻度（直接变更，状态栏确认文字） | any → idle |
| 工具门控 | 画轴工具：已加载图像即可用；拟合有效性体现在检查清单的轴状态徽标，无步骤门控 | — |

## 2. MarkTick（MarkXTicks / MarkYTicks 步）

| 手势 | 行为 | 状态流转 |
|---|---|---|
| 空白处单击 | 先显示临时标记 → TickFitter 阶段一定位 → 刻度线出现；每次增/删/拖后阶段二（等间距最小二乘）重跑，面板实时显示残差 | idle → placed(n) |
| 单击命中已有刻度 | 选中（高亮），**不新增**；两刻度距离 < 命中半径时取最近者 | placed(n) → selected |
| 拖动选中/直接拖动刻度 | 移动该刻度（直接变更），阶段二实时重算 | selected → dragging → placed(n) |
| Delete / 右键选中刻度 | 删除（直接变更），阶段二重算 | placed(n) → placed(n-1) |
| 显式跳过本轴 | 面板下拉选择"跳过 X/Y 刻度"，写入 calibration 标记；**与图类型无关**；**不允许两轴同时跳过**；被跳过轴数据坐标按序号计（Y 跳过示例：EIS 阻抗谱） | — |
| **禁止行为** | 不存在"第三个点击替换"；刻度密集区单击只选最近，不新增 | F2.3 |
| 工具门控 | 标刻度工具：对应轴线已画出且未跳过时可用；刻度不足在检查清单黄标警告 | — |

## 3. PlaceMarker（marker 引导模式）

| 手势 | 行为 | 状态流转 |
|---|---|---|
| 工具门控 | 取点工具：≥1 轴已校准时可用，否则置灰 + tooltip"至少校准一个轴：画出轴线并标注刻度，或显式跳过" | — |
| 单击 | 放置当前标记（临时态，高亮色） | idle → placing |
| 方向键 / Shift+方向键 | 微调当前标记；对已确认的最后一个标记也可用 | F3.2 |
| Enter / 再次单击同位置 | Confirm → 按序列 chartType 自动 refine（散点→暗中心质心 refineScatter / 柱状→柱顶边缘 refineBar）→ 提交当前序列 → 自动进入下一个待放置标记 | placing → confirmed(n) → placing |
| Esc | 取消当前未确认标记（已确认的不动） | placing → confirmed(n) |
| Delete | 删除已确认的最后一个标记 | confirmed(n) → confirmed(n-1) |
| 显示 | 已确认标记全程持久显示（低透明度），当前标记高亮；面板实时"已确认 N 个" | F3.2 / 铁律 4 |

## 4. 跨工具事项

- **chartType 归属**：chartType（散点/柱状）是**序列属性**，只决定 marker 确认时调用 refineScatter 还是 refineBar，交互手势本身不变；切换序列只改"当前序列"，其他序列点照常全量绘制。
- **取点模式**：Web 版仅保留 marker 逐点确认模式（Q6）；C++ 版曾有的自由点（EditPoints）模式废弃，取点一律走 marker 状态表。
- **无步骤框架**：不存在"重进步骤"；切换工具、校准返工均不清任何数据，坐标由铁律 2 级联重算。
- **裁剪/旋转等图像编辑**：见 `architecture.md` 6.6，不经过本表；其撤销路径见 Q5。
