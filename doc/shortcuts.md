# 快捷键表（定稿，M5-3）

> 对应 interaction-spec §0–§3 与 architecture.md §6.3。全局规则：**文本框聚焦时全部快捷键让位文本编辑**。

## 画布导航（任何工具下可用）

| 输入 | 行为 |
|---|---|
| 滚轮 | 以光标为中心缩放 |
| 中键拖动 / 按住空格 + 左键拖动 | 平移 |

## 通用编辑

| 按键 | 行为 |
|---|---|
| Delete | 删除选中轴线（连带其刻度）/ 选中点 / 选中刻度；取点工具下无选中时 = 先撤掉最后一个未确认标记，没有未确认标记时删除当前序列最后一个已确认标记 |
| Esc | 取消全部未确认标记；否则取消点/刻度/轴线选中；裁剪中 = 取消裁剪 |
| Enter | 取点：按放置顺序提交全部未确认标记（按序列 chartType 一次批量 refine）并进入下一个；裁剪中 = 确认裁剪 |

## 画轴工具（drawXAxis / drawYAxis）

| 输入 | 行为 |
|---|---|
| 沿轴线拖动 | 画近似线段，松开即拟合（已有轴线时替换，拖动中 warning 预告） |
| 单击轴线 | 选中轴线（光晕高亮），再按 Delete 删除 |
| 单击空白 | 取消轴线选中 |

## 取点工具（extractMarker，需先新建序列并选择图表类型）

| 输入 | 行为 |
|---|---|
| 单击空白 | 放置未确认标记：面板「批量取点」关 = 替换为单个标记；开 = 追加（例如每根柱子点一个，Enter 一次全部拟合） |
| 拖动未确认标记 | 移动该标记（不新增） |
| 按下已有点 | 选中（不新增） |
| 按住已有点拖动 | 超过 3 屏幕像素后移动该点 |
| 方向键 | 微调选中点（含刚确认的最后一个），步进面板可调（默认 1px） |
| Shift + 方向键 | 步进 ×10 |

## 刻度工具（markTickX / markTickY）

| 输入 | 行为 |
|---|---|
| 单击空白 | 放置刻度（空心 = 待拟合，画在点击处） |
| 按下已有刻度 | 选中最近的（不新增，F2.3） |
| 拖动刻度 | 超过 3 屏幕像素后移动，回到待拟合态，刻度值保留；已拟合刻度只沿轴移动 |
| Delete | 删除选中刻度 |

## PDF 选页弹窗（打开期间画布快捷键全部让位）

| 输入 | 行为 |
|---|---|
| 单击缩略图 / ↑↓ | 选页（右侧大预览） |
| 双击缩略图 / Enter | 按所选分辨率整页导入 |
| Esc | 关闭弹窗（检查器「选择页面…」可重新打开） |

## 双击

画布上不使用双击（v1.4 取消双击抓起）；双击等同两次单击，绝不新增或删除。唯一的双击是 PDF 选页弹窗里双击缩略图导入。
