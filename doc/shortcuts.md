# 快捷键表（定稿，M5-3）

> 对应 interaction-spec §0–§3 与 architecture.md §6.3。全局规则：**文本框聚焦时全部快捷键让位文本编辑**。

## 画布导航（任何工具下可用）

| 输入 | 行为 |
|---|---|
| 滚轮 | 以光标为中心缩放 |
| 中键拖动 / 按住空格 + 左键拖动 | 平移 |

## 通用编辑

| 按键 | 行为 |
|---|---|
| Delete | 删除选中点 / 选中刻度；取点工具下无选中时 = 删除当前序列最后一个已确认标记 |
| Esc | 取消当前未确认标记；否则取消点/刻度选中；裁剪中 = 取消裁剪 |
| Enter | 取点：提交当前标记（按序列 chartType 自动 refine）并进入下一个；点被抓起时 = 放下；裁剪中 = 确认裁剪 |

## 取点工具（extractMarker）

| 输入 | 行为 |
|---|---|
| 单击空白 | 放置当前标记（未确认态，可拖动微调） |
| 单击已有点 | 选中（不新增） |
| 双击已有点 | 抓起跟随鼠标；单击或 Enter 放下 |
| 方向键 | 微调选中点（含刚确认的最后一个），步进面板可调（默认 1px） |
| Shift + 方向键 | 步进 ×10 |

## 刻度工具（markTickX / markTickY）

| 输入 | 行为 |
|---|---|
| 单击空白 | 放置刻度（空心 = 待拟合） |
| 单击已有刻度 | 选中最近的（不新增，F2.3） |
| 拖动刻度 | 移动并回到待拟合态，刻度值保留 |
| Delete | 删除选中刻度 |

## 双击通则（G4）

双击 = 选中（点/刻度/轴线）；空白处双击无操作；双击绝不新增或删除。
