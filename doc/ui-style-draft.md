# UI 风格规格（草案 v0.3）— 单色仪器风 · 全亮色 · 无顶栏横向布局

> 状态：`草案 v0.3`，待 owner 确认。
> v0.2 → v0.3 修订：① 取消顶栏与步骤条（垂直空间全部让给画布）；② 取消靛蓝强调色，改**单色仪器风**；③ 新增工具门控与校准检查清单的组件规格。
> 已确认方向：极简扁平、全亮色、阴影仅浮层、中文界面、紧凑密度。

---

## 1. 设计方向

- **单色仪器风**：界面颜色只有黑 / 白 / 灰 + 三个语义色（成功绿 / 警告橙 / 错误红），且语义色只用于状态指示与画布读图，不做装饰。视觉参照：VS Code、Linear、测量仪器面板，而非消费级网站。
- **无彩色强调色**："当前 / 选中 / 主按钮"职能由深炭色 `--ink` 以反白手法承担。
- **画布语义色保留**（拟合成功绿、失败橙、内外点）：服务"读图"这一功能性需求，多序列色盘同理。
- **极简扁平**：无渐变、无纹理；层级靠留白、字号、字重、1px 边框。
- **圆角**：控件 4px，面板区块 6px，浮层 8px。
- **阴影**：仅浮层（tooltip、下拉、情境工具条）。
- **密度**：紧凑，控件高 28px，正文 13px 为主。

## 2. 布局（无顶栏；垂直 chrome 仅状态栏 24px）

### 布局原则

用户的图多为 4:3 及相近比例（8:6、12:9、9:7），**图像显示尺寸由窗口高度决定**。因此一切 chrome 只许横向生长（左工具轨、右检查器），垂直方向只保留一条 24px 状态栏。顶栏整个取消：浏览器标签页承担应用名职能，文件操作归入左轨下段。

### 整体线框

```
┌────┬────────────────────────────────────────┬────────────┐
│ 工 │                                        │ 检查器      │
│ 具 │      画布（浅灰工作台底 #E9E9E6）          │ 248px     │
│ 轨 │      图像按自身比例占满可用高度            │ ┌─────────┐│
│ 48 │                                        │ │校准检查  ││
│ px │   ┌─ 情境工具条（编辑/取点时悬浮出现）─┐    │ │清单      ││
│    │   └──────────────────────────┘    │ ├─────────┤│
│ 文 │                                        │ │当前工具  ││
│ 件 │                                        │ │上下文参数││
│ 操 │                                        │ └─────────┘│
│ 作 │                                        │ 可折叠至 0 │
├────┴────────────────────────────────────────┴────────────┤
│ 状态栏 24px：当前工具提示 ｜ 像素坐标 ｜ 拟合残差 ｜ 已确认 N    │
└────────────────────────────────────────────────────────────┘
```

### 区域职责

- **左工具轨（48px）**
  - 上段六个工具图标：画 X 轴｜画 Y 轴｜标 X 刻度｜标 Y 刻度｜取点｜编辑图像
  - 下段文件操作：打开｜保存项目｜导出 CSV｜撤销（图像编辑）
  - 被门控的工具**置灰 + tooltip 原因**（门控表见 `architecture.md` 6.1）；工具可用性本身承担引导职能
- **右检查器（248px，可折叠至 0）**
  - 顶部：**校准检查清单**（永远可见）——图像加载 ✓、X 轴四态、Y 轴四态、当前序列点数
  - 下方：当前工具的上下文参数（刻度列表与残差、序列管理、导出按钮与校验红字）
- **情境工具条**：悬浮画布左上，按需出现（编辑阶段给裁剪/旋转/对比度，取点阶段给散点/柱状切换与调试层开关），收起时画布零遮挡
- **状态栏（24px）**：铁律 4 的落点——当前工具提示、像素坐标、拟合残差、已确认计数

### 校准检查清单的轴四态视觉

| 轴状态 | 视觉 |
|---|---|
| 未设置 | `--text-faint` 灰字"未设置" |
| 轴线已画 · 缺刻度 | warning 黄标"缺刻度" |
| 已校准 | success 绿勾 + 残差数值（如 `✓ 0.3px`） |
| 已跳过 | 灰字"按序号" |

## 3. 设计 Token

### 3.1 颜色

| Token | 值 | 用途 |
|---|---|---|
| `--bg-workbench` | `#E9E9E6` | 画布工作台底 |
| `--bg-panel` | `#FFFFFF` | 工具轨、检查器、状态栏 |
| `--bg-subtle` | `#F4F4F2` | 分区、表头、hover 背景 |
| `--border` | `#E0E0DC` | 1px 分隔线、控件边框 |
| `--border-strong` | `#C4C4BF` | 输入框默认边框、拖拽把手 |
| `--text-primary` | `#1B1B18` | 主文字 |
| `--text-secondary` | `#5C5C56` | 次要文字、单位 |
| `--text-faint` | `#8F8F88` | 禁用、占位、空状态 |
| `--ink` | `#1F1F1E` | 主按钮底、活动工具底、选中描边 |
| `--ink-subtle` | `#E8E8E5` | 选中行底、激活项底 |
| `--success` | `#2F9E44` | 拟合成功、校验通过（清单绿勾） |
| `--warning` | `#E8890C` | 缺刻度警告、**替换预告** |
| `--danger` | `#D64545` | 拟合失败、内联错误文字 |
| `--focus-ring` | `#1F1F1E`，2px，offset 1px | 键盘焦点环 |

### 3.2 画布绘制语义色（render 层规范）

| 对象 | 样式 |
|---|---|
| 手绘预览线（未提交） | ink 虚线 2px |
| 拟合成功轴线/刻度 | success 实线 2px |
| 拟合失败 | warning 候选线 + success/danger 内/外点 + 扫描带 ink 10% 填充 |
| 当前 marker | ink 实心 + 中心十字 |
| 已确认 marker | ink 40% 透明实心（铁律 4：全程可见） |
| 数据点（按序列色盘） | 实心圆，屏幕恒定 r=4px |
| 选中对象 | 白色外圈 2px + ink 描边 |
| 替换预告 | 目标 warning 描边 + 状态栏 warning 文字 |

### 3.3 序列色盘（多序列区分属功能性用色）

`#4F46E5` `#2F9E44` `#E8890C` `#D64545` `#0CA678` `#1971C2` `#AE3EC9` `#66A80F`

### 3.4 字体

- 字体栈：`-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- 数字/坐标/残差：`ui-monospace, Consolas, monospace`
- 字号阶梯：20（应用标题）/ 15（面板标题）/ 14（按钮、强调）/ 13（基准正文）/ 12（辅助、表格、状态栏）

### 3.5 间距与尺寸（4px 网格）

间距 4 / 8 / 12 / 16 / 24；控件高 28px；工具轨 48px；检查器 248px；状态栏 24px；面板内边距 12px。

## 4. 组件清单与状态规范

| 组件 | 规格要点 |
|---|---|
| 工具轨图标按钮 | 24px 图标 / 40px 点击区；激活 = `--ink` 底白图标；被门控置灰 + tooltip 原因（铁律 5：禁用必给原因） |
| 主按钮 | `--ink` 底白字；disabled = `--bg-subtle` 底 + `--text-faint` 字 + tooltip 原因 |
| 次按钮 / ghost | 白底 + border / 无边框仅 hover 出底 |
| 数字输入 | 高 28px，聚焦 ink ring，等宽数字右对齐 |
| 下拉（跳过刻度等） | 白底 border，选项面板为浮层 |
| 检查清单行 | 轴名 + 四态徽标（见 2 节表）+ 残差数值；整行 hover 高亮并可点击跳转到对应工具 |
| 序列列表项 | hover `--bg-subtle`；选中 `--ink-subtle` 底 + ink 左条；当前序列 badge 显示点数 |
| Badge | 12px 圆角块，`--bg-subtle` 底 |
| Tooltip | 浮层，延迟 400ms；门控原因、坐标读数、刻度值均用它 |
| 情境工具条 | 浮层圆角 8px（阴影允许区），激活项 `--ink-subtle` 底 |
| 空状态 | 居中线稿图标 + 一句行动指引（如"拖入或点击打开一张图片"） |

所有可交互元素必须有 hover / active / disabled / focus 四态。

Token 结构预留暗色映射，M1–M5 不做，后期需要再出一版 dark token。
